# Tragogo

Tragogo គឺជាកម្មវិធី Android browser ដែលកែប្រែចេញពី DuckDuckGo Android។

## ទាញយក (Download)

[⬇️ ទាញយក Tragogo.apk](https://github.com/los323527-code/Tragogo/releases/latest/download/Tragogo.apk)

### របៀបដំឡើង
1. ចុចប៊ូតុងទាញយកខាងលើ
2. បើកឯកសារ `Tragogo.apk`
3. ប្រសិនបើទូរស័ព្ទសួរ សូមអនុញ្ញាត **Install unknown apps**
4. ចុច Install

## អំពី

គម្រោងនេះផ្អែកលើ [DuckDuckGo Android](https://github.com/duckduckgo/Android) ហើយចែកចាយក្រោម [Apache License 2.0](LICENSE)។
